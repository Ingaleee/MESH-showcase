Explicit laboratory boundaries

This static presentation does not expose a backend. Hosted machines are ephemeral. Kubernetes is single-node. Recovery uses a small, quiescent fixture.

Multi-node HA, online WAL/PITR, large-restore throughput, permanent backup retention and a long production SLO window are not demonstrated. Partners and payments are simulators; uploaded code is never executed.
