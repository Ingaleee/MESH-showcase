# Доставка showcase: решения и границы

8 октября 2026. Независимая копия продукта, основной MESH не участвует.

- Ruby остаётся modular monolith; ограниченные страницы читаются через отдельные query services. Signed keyset cursors привязаны к actor/project/filter и истекают через 30 минут. Count-запросы остаются точными и растут по стоимости с данными; substring search пока без специализированного индекса. Это осознанная граница, а не обещание O(1) для всей страницы.
- Production Docker использует Debian slim: существующие Ruby native gems и Node tooling уже проверены на glibc. Alpine из учебных заданий не является самостоятельным требованием продукта.
- Миграции запускаются отдельным шагом владельцем БД; приложение использует ограниченную login-role. Новые индексы создаются CONCURRENTLY. Rollback меняет образы и не откатывает данные/схему; совместимость каждой миграции нужно проверять перед выпуском.
- Файлы — постоянный отдельный том, общий для API/worker. Локальный Compose демонстрирует один host; такой Disk storage не даёт multi-node HA.
- Публичный вход — один HTTPS edge на loopback. В локальной среде используется отдельный внутренний CA; сертификат нельзя считать публично доверенным.
- GitHub hosted проверяет PR; self-hosted runner только в отдельной доверенной private repository/VM. Одного if в public workflow недостаточно для изоляции runner от недоверенного workflow-кода.
- Секреты generated локально, ignored и не входят в образы/evidence. GitHub, VM registration и внешняя публикация отложены пользователем.
