## Исторический статус на 8 октября

Техническая часть семи ближайших этапов выполнена в scope showcase: hosted CI, Ansible Ubuntu, signed release и rollback, Ruby/SQL gaps, current Publishing restore, live telemetry/current Kubernetes и сценарий показа. Все четыре hosted workflows относятся к release source 7f7a0e3. Документационные commits после этой ревизии не переименовывают её в новый проверенный image.

Каталог проверяется командой `node scripts/check-hosted-acceptance.mjs`: динамическое число tests, zero skips/flaky, source/run context, report hashes, image scan/provenance, actual runtime и failed Helm history. Полные raw artifacts хранятся в Actions 30 дней; выбранные sanitized reports и их исходные/published hashes сохранены в Git.

Полная [планка Q01–Q14](quality-bar.md) имеет оставшиеся критерии: mixed-load/overload, полная crash/mutation matrix, separate-VM/offsite/key custody и длительное production SLO окно. Single-node Kubernetes не подтверждает physical HA, file-scanner/partner workload в кластере и multi-node PVC strategy. Локальный encrypted/quiescent restore не подменяет потерю исходной VM.

Личная репетиция и две настоящие коммерческие истории кандидата требуют его участия. Автоматический browser/CLI сценарий не заменяет умение объяснить решения. Локальный Docker engine восстановил доступность после неуспешной обычной restart-команды; принудительное завершение WSL не выполнялось. После разрешённого запуска существующего основного MESH его homepage/session, showcase homepage/session и Grafana health вернули HTTP 200. Авария оставила служебные Rails PID-файлы; showcase теперь использует --pid /dev/null и прошёл отдельный SIGKILL → start → HTTP recovery. [Локальный отчёт](evidence/acceptance-oct08/local-docker-recovery.json) сохраняет этот scope. Финальный documentation CI 37839685069 остановился на checksum mismatch upstream UI-архива Alertmanager; закреплённый digest совпал с официальной metadata, checksum-файлом и независимым повторным скачиванием. Защита не отключена: fresh CI [37844053157](https://github.com/Ingaleee/MESH-showcase/actions/runs/37844053157) прошёл эту сборку, но дал 12/13 browser checks из-за мгновенного измерения mobile layout после resize. Локальные измерения обнаружили загрузку fonts после смены viewport; persistent overflow локально не воспроизведён. Проверка теперь ждёт fonts и требует тот же предел ширины, сохраняя geometry при отказе. Следующий whole pipeline должен пройти все критические шаги без retries/skips.
