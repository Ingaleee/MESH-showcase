Скриншоты действующего локального приложения, не макеты. Иллюстрации — вымышленный бренд NORA. Авторское предложение на кофейном демо-проекте показано в черновике; браузерный сценарий отправки проверялся на отдельных проектах.

Проверки и привязка к исходникам: [verification.json](verification.json). Production frontend проверяется отдельным образом с тестовым прокси к локальному API; полный пользовательский сценарий — через основной Caddy на localhost:3100.
