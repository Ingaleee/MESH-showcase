На скриншоте демо-проекта показана заполненная, неотправленная форма. Вложение `brand-paper.png` — настоящее редакционное изображение MESH, загруженное как пример автора. Статус проверки файла соответствует моменту съёмки. Отправка, сохранение версии брифа и скачивание проверены на отдельных проектах E2E.

`verification.json` связывает проверки с хешами исходников и production image. 52 Rails-примера, 7 браузерных сценариев, пять ширин без переполнения, Axe desktop/mobile без нарушений. `file-pipeline-check.json` подтверждает реальную обработку ClamAV/Solid Queue и скачивание заказчиком при отказе гостю. `production-check.json` проверяет CSP, изображения, восстановление черновика и возврат к брифу. `playwright-full.json` — полный успешный прогон.
