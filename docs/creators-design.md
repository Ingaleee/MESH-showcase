# Каталог авторов MESH

Страница `/creators` переработана 7 октября 2026 года по предоставленному референсу. Она продолжает главную: тёплый светлый фон, Manrope, общая верхняя навигация, чёрные кнопки, фиолетовые акценты, портреты и визуальные примеры. На компьютере четыре колонки, на планшете две, на телефоне одна. В сетке размещены создание проекта и приглашение оформить профиль; внизу — широкий тёмный баннер.

## Поведение

- Поиск по имени, специализации, описанию и навыкам использует Rails API; сервер экранирует SQL wildcard-символы. Запоздавший ответ предыдущего поиска не заменяет актуальный результат.
- Пять направлений определяются по указанным в профиле специализации и навыкам. До появления отдельного поля направления это явно описанное правило отображения, а не новая доменная модель.
- Фильтры стоимости за проект в рублях, сортировка по имени и стоимости, сочетание с поиском и сохранёнными авторами. При разных валютах сортировка сначала группирует их; курс валют не предполагается.
- Закладки хранятся в текущем браузере под `mesh:saved-creators:v1`. Ошибка хранилища отображается пользователю; интерфейс не заявляет об успешном сохранении.
- Подробный профиль открывается в диалоге с прямой ссылкой `/creators?profile=<id>`. Ссылка работает с главной и после обновления страницы. Escape закрывает диалог и очищает параметр. Это ещё не отдельная страница с загруженным портфолио.
- Из профиля можно перейти к публикации проекта. Проект публикуется для предложений авторов; кнопка не создаёт частное приглашение выбранному автору.
- «Мой профиль» использует полную загруженную подборку, поэтому фильтрация каталога не очищает редактор собственного профиля. При ошибке загрузки пользователь повторяет запрос, прежде чем редактировать.
- У поиска есть очистка и Ctrl/Cmd K. Загрузка, отсутствие результатов и ошибка API имеют отдельные состояния; ошибка предлагает повторить запрос.
- Кнопки создания проекта открывают действующую форму, гостю сначала показывается вход. Навигация к категориям и шагам работы возвращает на нужную секцию главной.

Каталог сохраняет существующее ограничение API: до 40 профилей на запрос. Для большого каталога нужны серверные фильтры, курсорная пагинация и получение конкретного профиля/собственного профиля отдельным запросом.

## Изображения

Новый лист с двумя вымышленными портретами создан встроенным `image_gen`, сохранён в `apps/web/public/images/creators/portrait-duo.png`. [Полный запрос и путь](creator-image-prompts.json). Первые четыре портрета и изображения направлений используются из существующего набора главной. Это демонстрационные иллюстрации; в каталоге и профиле они обозначены как демо, а не как работы конкретного автора. Рейтинги, онлайн-статус и неподтверждённые достижения не добавлены.

Next Image оптимизирует изображения. Для листа из четырёх портретов каталог запрашивает размер с учётом всей полосы, чтобы лица оставались чёткими при увеличении в профиле. Motion управляет появлением и наведением на карточки; настройка уменьшения анимации учитывается.

## Проверки и скриншоты

[Итоговый отчёт и SHA-256 проверенных файлов](screenshots/creators-redesign/verification.json).

- TypeScript, Prettier, границы модулей, RuboCop изменённых Ruby-файлов, production Docker-сборка.
- Rails: 39 примеров без ошибок, включая поиск по имени, навыку и буквальным `%`/`_`, а также отсутствие приватных полей аккаунта в публичном ответе.
- Playwright: каталог, комбинированные фильтры, закладки, прямые ссылки, сохранение данных редактора при поиске; существующий сценарий от публикации проекта до приёмки и расчётов. Автоматическая проверка WCAG 2.1 AA включает каталог, подробный профиль и вход.
- [Дополнительные проверки действий](screenshots/creators-redesign/interactions.json): навигация с главной, все направления, бюджет, сортировка, ошибки сети/хранилища и гонка поисковых ответов.
- [Четыре проверки форм для заказчика](screenshots/creators-redesign/project-actions.json): создание проекта из меню, карточки в каталоге, нижнего баннера и подробного профиля без публикации тестовых проектов.
- [Пять ширин экрана](screenshots/creators-redesign/browser-check.json): 320, 390, 768, 1024 и 1440 px, изображения и JavaScript.
- [Production-проверка](screenshots/creators-redesign/production-check.json): CSP/nonce, оптимизация портрета в WebP, поиск, диалог, появление и наведение карточек. Для standalone frontend запросы браузера перенаправляются на локальный Rails API; это условие отражено в отчёте.
